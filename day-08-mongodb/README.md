## 🧠 Key Takeaways

* SQL databases store data in tables and rows.
* NoSQL databases can store data in more flexible structures.
* MongoDB is a NoSQL document database.
* MongoDB stores data as documents inside collections.
* MongoDB provides queries for finding and modifying data.
* MongoDB supports CRUD operations.
