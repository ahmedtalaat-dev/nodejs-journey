# 🚀 Day 03 — Node.js Core Modules

Today I learned about some of the most important **built-in Node.js Core Modules**.

## 📚 Lessons

### 1. 💻 OS Module

The `os` module provides information about the operating system and computer.

I learned how to get:

- Operating system platform
- CPU architecture
- Hostname
- Home directory
- Total memory
- Free memory
- CPU information
- System uptime

### 2. 📁 Path Module

The `path` module provides utilities for working with **file and directory paths**.

I learned how to:

- Join paths
- Get file names
- Get directory names
- Get file extensions
- Parse file paths

### 3. 📄 File System Module

The `fs` module allows Node.js applications to interact with the **file system**.

I learned how to:

- Create files
- Read files
- Write files
- Append content
- Check if a file exists
- Create directories

### 4. 🌐 HTTP Module

The `http` module allows us to create **HTTP servers** and handle requests and responses.

I learned how to:

- Create a basic HTTP server
- Handle incoming requests
- Send HTTP responses
- Work with `req`
- Work with `res`
- Run a server on a specific port
