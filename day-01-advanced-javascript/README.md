# Day 1 — Advanced JavaScript

Today I focused on advanced JavaScript concepts that are important for understanding how Node.js works under the hood.

## 📚 Topics Covered

### 1. Asynchronous JavaScript

- Synchronous vs Asynchronous code
- Callbacks
- Promises
- `async/await`
- Handling asynchronous operations

### 2. Event Loop

- Call Stack
- Runtime APIs
- Callback Queue
- Microtask Queue
- Event Loop
- How JavaScript handles asynchronous code

## 🧠 Key Takeaways

- JavaScript is single-threaded but can handle asynchronous operations.
- The Event Loop coordinates the execution of asynchronous tasks.
- Promises and `async/await` provide cleaner ways to work with asynchronous operations.
- Understanding the Event Loop is essential for understanding Node.js.

## 🎯 Goal

Build a strong understanding of JavaScript's runtime and asynchronous behavior before diving deeper into Node.js.
