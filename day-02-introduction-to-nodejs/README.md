## 🟢 What is Node.js?

- **Node.js** is a **JavaScript runtime environment** that allows us to run JavaScript code outside of the browser.
- Normally, JavaScript runs inside a web browser such as Chrome, Firefox, or Edge and is mainly used to build interactive web pages.
- With Node.js, we can run JavaScript directly on our computer or a server. This makes it possible to use JavaScript for **backend development** and server-side applications.
- Node.js is built on Google's **V8 JavaScript engine**, which is the same JavaScript engine used by Google Chrome. V8 is responsible for executing JavaScript code.
- Node.js also provides APIs that allow JavaScript to interact with the operating system, files, networks, and other resources.

## ⚙️ Why Use Node.js?

Node.js can be used to build:

- Web servers
- REST APIs
- Backend applications
- Real-time applications
- Command-line tools

## 📥 Installing Node.js

I installed Node.js on my computer.

To check the Node.js version:

```bash
node -v
```

To check the NPM version:

```bash
npm -v
```
