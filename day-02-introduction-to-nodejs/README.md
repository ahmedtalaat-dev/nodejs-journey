## 🟢 What is Node.js?

**Node.js** is a **JavaScript runtime environment** that allows us to run JavaScript outside of the browser.

Node.js is built on Google's **V8 JavaScript engine**.

## ⚙️ Why Use Node.js?

Node.js can be used to build:

- Web servers
- REST APIs
- Backend applications
- Real-time applications
- Command-line tools

## 📥 Installing Node.js

I installed Node.js on my computer.

To check the Node.js version:

```bash
node -v
```

To check the NPM version:

```bash
npm -v
```

## 📁 Creating My Node.js Folder
