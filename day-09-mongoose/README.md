# 🚀 Day 09 — CRUD Operations with Mongoose

Today I learned how to build a complete **CRUD API** using:

- Node.js
- Express.js
- MongoDB
- Mongoose

I created a `students` endpoint that can create, read, update, and delete students.

## 📚 What I Learned

- What Mongoose is
- Connecting Express to MongoDB
- Creating Mongoose schemas
- Creating Mongoose models
- Using controllers
- Using Express routes
- Creating CRUD operations
- Working with MongoDB through Mongoose

## 🧩 What is Mongoose?

Mongoose is an ODM (Object Data Modeling) library for MongoDB and Node.js.

It allows us to define the structure of our MongoDB documents using schemas and provides methods for interacting with the database.
